# Homebrew Tap

## Bento

macOS ネイティブの Web アプリ用ブラウザ。

```bash
brew install --cask tadashi0713/tap/bento
```

更新は `brew upgrade --cask bento` です。

## DemoCapture

macOS ネイティブのデモ収録アプリ。画面・カメラ・マイクを 1 本の動画に書き出します。

```bash
brew install --cask tadashi0713/tap/democapture
```

更新は `brew upgrade --cask democapture` です。
